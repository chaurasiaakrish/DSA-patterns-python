When do I use Binary Search?

This is the most important part.

Don't memorize:

"Binary search = sorted array."

That's useful, but incomplete.




Pattern 1: Sorted/searchable space

Example:

[1, 3, 5, 7, 9, 11, 15]

Question:

Find 9.

Very obvious binary search.



Pattern 2: You can eliminate half the possibilities

This is the real idea.

Ask yourself:

"If I check the middle, can I prove that half of the remaining possibilities can be discarded?"

If YES → binary search may be applicable.

If NO → binary search probably isn't.
